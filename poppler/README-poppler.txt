This folder contains unmodified Windows builds of Poppler's command-line tools
(pdfimages.exe, pdfinfo.exe) and the libraries they need.

Poppler is free software released under the GNU GPL (v2/v3).
Project:  https://poppler.freedesktop.org/
Windows builds: https://github.com/oschwartz10612/poppler-windows
Source code for these binaries is available from those links.
