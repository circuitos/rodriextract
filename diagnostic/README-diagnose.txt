rodriextract diagnostic - instructions
======================================

Use this only if rodriextract does not start or does not work.
It finds out why and writes the answer to a text file.
It does not change anything on your computer (it only makes temporary files and deletes them).

1. Double-click   rodriextract-diagnose.cmd   (in this folder)
2. Wait about a minute. Windows may flash open and close, and a small test
   window may appear. That's normal. Don't click anything.
3. When it says DONE, a folder opens with  rodriextract-diagnostic.txt  selected.
   Send that file to the person who asked you to run this.

Note: the report includes your computer name, user name and file paths.

If a Windows security prompt appears, or something is "blocked", please take a
screenshot of it and send that as well - that is useful information too.
